Swift Backup 是一个非常好用的备份软件——它可以备份应用、数据，甚至还能备份部分资源文件。

但是它有一个缺陷——它的备份文件默认加密，并且密码无从得知。

根据我的测试，在 A 手机上生成的备份，在 B 手机上可以正常还原。这说明所有密钥是相同的（加密加了个寂寞），官网上的文档也证实了这一点。

简单搜索了一下，有很多人讨论了加密规则，但是没有给出密码。看来我们还是得自己动手了。

首先我们使用 jadx 反编译 dex，得到 Java 源代码。
通过观察，我们可以发现它使用了7-Zip-JBinding作为第三方库，密码肯定通过库的 API 传入。我们不妨去看看文档：

可以看到，通过传入实现了cryptoGetTextPassword方法的类MyCreateCallback，库内部就会自动完成加密操作。

那么，我们只需要找到cryptoGetTextPassword这个方法，就能找到密码了。
